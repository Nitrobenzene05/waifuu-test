# Waifuu 测试版

这是 Waifuu 的 Windows 朋友测试仓库。星咏リア是内置的默认角色。

从 [Waifuu 1.7.0 Release](https://github.com/Nitrobenzene05/waifuu-test/releases/tag/v1.7.0) 下载 `Waifuu-1.7.0.zip`。

## 安装

1. 在 Windows 上安装 Python 3.11。
2. 解压 ZIP，在解压后的 Waifuu 文件夹打开 PowerShell，运行 `powershell -ExecutionPolicy Bypass -File scripts/setup.ps1`。
3. 双击 `Waifuu.exe`。首次使用会下载鱼鱼姐中文音色，下载完成后可在本地合成。

想测试麦克风输入，可按压缩包内 README 的说明另装 SenseVoice。可以在本仓库的 Issues 提交测试反馈，附上 Waifuu 版本、Windows 版本和复现步骤即可。
